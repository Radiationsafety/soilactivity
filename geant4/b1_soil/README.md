# b1_soil — матрица чувствительности «источник в грунте — детектор на 1 м» и реконструкция активности

Развитие базового примера **Geant4 basic/B1** для пакета
[soilactivity](https://github.com/Radiationsafety/soilactivity):
моделирование полевой гамма-съёмки загрязнённой территории и проверка
реконструкции активности методами пакета по данным Монте-Карло.

## Физическая постановка

Плоский слой грунта (ICRU 53 sandy loam, ρ = 1.6 г/см³, тот же состав, что
`NIST_SOIL_COMPOSITION` в пакете), над ним воздух. На площадке 10×10 м сетка
**5×5 ячеек с шагом 2 м**:

```
   вид сбоку                          вид сверху (сетка 5x5, шаг 2 м)

   детектор i  o  <- 1 м над землёй          o---o---o---o---o
   ~~~~~~~~ воздух ~~~~~~~~~                 |   |   |   |   |
   --------- земля z=0 -------               o---o---o---o---o
        * <- источник j (глубина 10 см)      |   | * |   |   |   * - модельный источник
   ~~~~~~~~~~ грунт ~~~~~~~~~~               o---o---o---o---o
```

1. **Матрица чувствительности A** (25×25): источник Cs-137 (661.7 кэВ,
   выход 0.851) поочерёдно помещается в каждую ячейку грунта, детектор —
   поочерёдно на высоту 1 м над каждой ячейкой. Элемент
   `A[i,j]` — мощность H*(10) в точке детектора *i* от источника активностью
   1 Бк в ячейке *j*, **Зв/с на Бк**.
2. **Модельный источник** («измерение»): три «горячих пятна»
   (1×10⁸, 2×10⁸, 5×10⁷ Бк). Детектор обходит все 25 позиций — получается
   вектор измерений `b[i] = Σⱼ A[i,j]·x[j]` (в мкЗв/ч).
3. **Реконструкция**: методами пакета `soilactivity` (MLEM и Тихонов с
   неотрицательными ограничениями) активность `x` восстанавливается из
   `(A, b)` и **сверяется с истинным модельным источником**.

Детектор — воздушная сфера радиусом 15 см (габарит ICRU-сферы). Скоринг —
**флюенс фотонов, вошедших в сферу**, по 48 логарифмическим бинам энергии
(10 кэВ…3 МэВ); отклик переводится в H*(10) через коэффициенты ICRP 74
(`soilactivity.h_star_10_over_phil`) уже в пост-обработке:

    H*(10)/распад = Σ_b (N_b/N) · h*(10)/Φ(E_b) / (π R²)

(число пересечений выпуклой поверхности ~ флюенс; для 1 Бк значение численно
равно мощности дозы, Зв/с). Дополнительно накапливается энерговыделение в
сферах (kerma-канал для взаимной сверки).

## Структура

```
geant4/b1_soil/
├── b1soil.cc, CMakeLists.txt        # main (паттерн B1) и сборка
├── include/ , src/                  # C++ (классы B1*, Geant4 10.7+ / 11.x)
│   ├── B1DetectorConstruction       # грунт + сетка + сферы-детекторы
│   ├── B1DetectorMessenger          # /b1soil/set* (геометрия, файл CSV)
│   ├── B1PrimaryGeneratorAction     # 1 событие = 1 распад, линии нуклидов,
│   │                                #   модельный источник (веса = активности)
│   ├── B1PrimaryGeneratorMessenger  # /b1soil/setGammaLine|addModelCell|...
│   ├── B1RunAction (+B1Run)         # накопители (спектры, edep) + CSV
│   └── B1SteppingAction             # скоринг флюенса и edep (по имени DetLV)
├── macros/
│   ├── sensitivity.mac              # матрица A: ПООЧЕРЁДНЫЙ обход
│   │                                #   детектор(24) × источник(24), 625 прогонов
│   ├── sensitivity_fast.mac         #   быстрый вариант: все детекторы сразу, 25 прогонов
│   ├── model_source.mac             # модельный источник + обход детектора, 25 прогонов
│   ├── model_source_fast.mac        #   быстрый вариант: 1 прогон
│   ├── model_cells.mac              # ячейки модельного источника (генерируется)
│   └── vis.mac                      # визуализация
├── python/
│   ├── b1soil_io.py                 # формат CSV, сетка спектра, ICRP 74, сборка A и b
│   ├── make_model_macro.py          # model.json -> macros/model_cells.mac
│   ├── build_sensitivity.py         # CSV -> A.npz (+ симметризация, cond(A))
│   └── reconstruct.py               # MLEM + Тихонов (soilactivity), сверка, графики
└── demo/                            # ПАЙПЛАЙН БЕЗ GEANT4
    ├── python_mc.py                 # numpy Монте-Карло (тот же CSV-формат)
    ├── demo_no_geant4.py            # оркестратор всего пайплайна
    ├── model.json                   # модельный источник (истина)
    └── out/                         # результаты: recon_map.png, *.csv, *.npz
```

## Сборка (Geant4 10.7+ / 11.x)

```bash
cd geant4/b1_soil
cmake -B build -S . -DGeant4_DIR=/путь/к/Geant4/lib/Geant4-11.x
cmake --build build -j8
cd build          # макросы и python-скрипты скопированы сюда
```

## Пайплайн с Geant4

```bash
# 1. Матрица чувствительности (поочерёдное размещение; ~30–60 мин в MT на 4 ядрах)
./b1soil macros/sensitivity.mac
#    быстрый эквивалент (25 прогонов вместо 625):
./b1soil macros/sensitivity_fast.mac

# 2. Модельный источник (править macros/model_cells.mac или сгенерировать):
python3 ../python/make_model_macro.py model.json ../macros/model_cells.mac
./b1soil macros/model_source.mac            # или model_source_fast.mac

# 3. Матрица A
python3 ../python/build_sensitivity.py results_sensitivity.csv --out A.npz

# 4. Реконструкция и сверка с истиной
python3 ../python/reconstruct.py A.npz results_model.csv model.json \
        --outdir out --noise 0.02
```

Основные команды (все с автоперестроением геометрии):

| Команда | По умолчанию | Описание |
|---|---|---|
| `/b1soil/setGridNx/Ny` | 5 | размер сетки |
| `/b1soil/setCellSize` | 2 m | шаг сетки |
| `/b1soil/setSrcDepth` | 10 cm | глубина источника |
| `/b1soil/setDetHeight` | 1 m | высота детектора |
| `/b1soil/setDetRadius` | 15 cm | радиус сферы-детектора |
| `/b1soil/setSoilDensity` | 1.6 g/cm3 | плотность грунта |
| `/b1soil/setDetMode` | all | `single` — поочерёдно; `all` — все сразу |
| `/b1soil/setDetIndex` | 0 | позиция детектора в режиме `single` |
| `/b1soil/setGammaLine` | Cs137 | `Cs137 \| Co60 \| Am241`, либо `addLine E yield` |
| `/b1soil/setSrcIndex` | 0 | ячейка источника (row-major `idx = iy*nx + ix`) |
| `/b1soil/addModelCell` | — | ячейка модельного источника: `x y z m активность Bq` |
| `/b1soil/useModelSource` | false | выбор ячейки распада ∝ активности |
| `/b1soil/setRunType` | SENSITIVITY | метка прогона в CSV (`MODEL` ставится автоматически) |
| `/b1soil/setOutputFile` | b1soil_runs.csv | CSV-файл результатов (append) |

Число распадов на прогон задаётся алиасом в макросах
(`/control/alias b1soilN 2000000`). Режим `single` — буквальное
«поочерёдное размещение», как в постановке задачи; `all` — все 25 воздушных
сфер в сцене сразу, физически эквивалентно (воздух на 662 кэВ почти
прозрачен, искажение < 0.01 %) и в 25 раз быстрее.

## Пайплайн без Geant4 (демо в этом каталоге)

`demo/python_mc.py` — векторизованный numpy Монте-Карло: фотоэффект +
комптоновское рассеяние (Клейн-Нишина) + когерентное (приближённо) в грунте
и воздухе, сечения из NIST XCOM через `soilactivity`. Пишет **тот же
CSV-формат**, что и Geant4-пример, поэтому вся последующая обработка
идентична:

```bash
cd demo
python3 demo_no_geant4.py            # полный прогон (~60 с): шаги 1–5 + сверка с point-kernel
python3 demo_no_geant4.py --fast     # быстрая проверка (~15 с)
```

## Результаты демо-прогона (5×5, шаг 2 м, Cs-137, глубина 10 см)

Модельный источник: 3.5·10⁸ Бк суммарно (ячейки (1,1) = 1.0·10⁸,
(2,2) = 2.0·10⁸, (3,2) = 5.0·10⁷ Бк). Матрица A — 6·10⁵ распадов на источник
(симметризация по D4), «измерение» — 4·10⁶ распадов + 2 % шума:

| Метод | Суммарная активность | ошибка суммы | L2-ошибка распределения | средняя ошибка горячих ячеек | косинус | Linfoot |
|---|---|---|---|---|---|---|
| **MLEM** (200 итер.) | 3.516·10⁸ Бк | **0.44 %** | 2.5 % | 3.3 % | 0.9998 | 0.988 |
| **Тихонов** (x≥0) | 3.550·10⁸ Бк | **1.44 %** | 5.1 % | 7.0 % | 0.9989 | 0.988 |
| Истина (модель) | 3.500·10⁸ Бк | — | — | — | 1.0 | 1.0 |

По ячейкам (истина → MLEM): (1,1) 1.00·10⁸ → 0.97·10⁸; (2,2) 2.00·10⁸ →
1.97·10⁸; (3,2) 0.50·10⁸ → 0.53·10⁸ Бк. Измеренная МАЭД 1.2…26.6 мкЗв/ч.
Карты: `demo/out/recon_map.png` (истина / MLEM / Тихонов / поле МАЭД).

Сверка Монте-Карло с аналитикой пакета (`demo/pk_vs_mc.csv`): в надире
point-kernel (прямой луч + фактор накопления ANS-6.4.3) даёт 0.58 от MC —
типичная точность point-kernel для полупространства «грунт–воздух»;
для смещённых детекторов PK занижает на 1–2 порядка, т.к. поле в воздухе
доминировано рассеянным излучением, вышедшим через всю поверхность грунта
(воздух на 662 кэВ практически прозрачен). Именно поэтому матрицу
чувствительности строят Монте-Карло, а не аналитикой.

Число обусловленности cond(A) ≈ 4.6 — задача слабо обусловлена в смысле
классической нормы (поле МАЭД очень «размазано»), но с неотрицательными
ограничениями (MLEM, Тихонов `x≥0`) восстанавливается устойчиво.

## Формат CSV и нормировки

Первая строка-шапка `# b1soil_version=1.0 nx=... detRadius_m=... nBins=48...`,
затем заголовок колонок (комментарий) и по одной строке на детектор за прогон:
`run_type, src_index, src_*_m, det_mode, det_index, det_*_m, n_decays, n_in,
edep_sum_MeV, edep_rms_MeV, sp_000..sp_047`.

* `n_decays` — распадов в прогоне; 1 событие = 1 распад (для Cs-137 14.9 %
  событий пустые — корректная нормировка на выход 0.851).
* Отклик на распад: `H*(10) = Σ_b (N_b/n_decays)·h*(10)/Φ(E_b)/(πR²)`.
* `run_type=SENSITIVITY` → элементы A; `MODEL` → вектор b.
* b физичен после умножения на суммарную активность модельного источника
  («измерение 1 с»): `b = b_per_decay · Σx` — это нормировка опыты, а не
  использование формы распределения.

## Приближения и примечания

* **Python-MC** (demo): электронный транспорт не моделируется (флюенс-скоринг
  это позволяет), когерентное рассеяние без атомных форм-факторов (выше
  150 кэВ — упругое с ~ (1+cos²θ)/2, ниже — поглощение). Систематика
  абсолютных значений — единицы процентов; для точных расчётов используйте
  Geant4-пример (там полный стандартный EM-конвейер FTFP_BERT).
* **Пакет soilactivity**: солверы `solve_mlem/solve_tikhonov` содержат
  абсолютный порог `eps=1e-10` — при A~10⁻¹⁷ (Зв/с на Бк) задача в
  `reconstruct.py` предварительно масштабируется (мкЗв/ч на Бк + нормировка
  на max A); решение при этом не меняется.
* Исправлен баг пакета: `_ELEMENT_ALIASES` в `buildup.py` не содержал
  водород, из-за чего `buildup_for_mixture` падал на любых смесях с H
  (в т.ч. на примере бетона из docstring самого пакета). Добавлен алиас
  `"H": "Hydrogen"`.
* Справочные числа в docstring `soilactivity.dosimetry` устарели (например,
  «6.49e-13» для h*(10)/Φ при 662 кэВ); корректное значение по ICRP 74 —
  ≈ 5.0·10⁻¹² Зв·см², код пакета его и выдаёт.

## Расширения

* Другой нуклид: `/b1soil/setGammaLine Co60` (в Python-MC поменяйте
  `E0_CS137` и линии) — для смеси добавьте строки в model.json и отдельные
  матрицы A на каждую линию.
* Другая сетка/глубина: `setGridNx/Ny, setCellSize, setSrcDepth` + те же
  параметры в `python_mc.py`/`model.json`.
* Учёт зданий/барьеров: см. `soilactivity.compute_visibility_matrix`.

## Зависимости

* Geant4 10.7+ / 11.x (только для Geant4-части), CMake ≥ 3.16
* Python 3.9+: `numpy`, `scipy`, `pandas`, `matplotlib`; пакет soilactivity
  (`pip install -e .` из корня репозитория)
